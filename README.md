# Практическая работа по HTML5 API

## Цель работы

Целью данной практической работы было изучение возможностей HTML5 API, а именно:
- навигация с использованием истории браузера;
- работа с Canvas API и анимацией;
- использование Web Worker для выполнения фоновых вычислений без блокировки интерфейса.

## Используемые технологии

В ходе выполнения работы были использованы следующие технологии:
- HTML5;
- CSS3;
- JavaScript;
- History API;
- Canvas API;
- Web Workers.

## Реализация навигации и History API

В приложении реализована навигация между разделами: **Главная**, **Canvas** и **Web Worker**.  
При переходе между разделами используется `history.pushState()`, за счёт чего переходы сохраняются в истории браузера.

Также добавлены кнопки **«Назад»** и **«Вперёд»**, которые позволяют перемещаться по истории переходов так же, как в обычном браузере.  
Событие `popstate` обрабатывается для корректного отображения нужного раздела при движении по истории.

## Canvas и анимация

Для работы с графикой использован элемент `<canvas>`.  
На холсте отображается анимированный шар, который движется и отскакивает от границ холста.

Анимация реализована с использованием функции `requestAnimationFrame()`, что обеспечивает плавное отображение и хорошую производительность.  
Управление анимацией осуществляется с помощью кнопок **«Запустить»** и **«Остановить»**.

Для оптимизации работы анимация автоматически останавливается при переключении на другой раздел.

## Использование Web Worker

Для выполнения тяжёлых вычислений был создан Web Worker в отдельном файле.  
В качестве задачи воркёр рассчитывает:
- количество простых чисел от 2 до N;
- сумму простых чисел в этом диапазоне.

Пользователь вводит число N и запускает вычисление с помощью кнопки **«Старт»**.  
Вычисления выполняются в фоновом потоке и не блокируют основной интерфейс страницы.

Результаты вычислений возвращаются обратно на страницу и отображаются пользователю.

## Обработка ошибок и пользовательские сообщения

В приложении предусмотрена обработка возможных ошибок:
- ввод некорректного значения;
- отсутствие поддержки Web Workers в браузере;
- ошибки, возникающие внутри веб-воркера.

Для информирования пользователя используется блок с сообщениями, в котором отображаются статусы выполнения операций и уведомления об ошибках или успешном завершении действий.

## Вывод

В результате выполнения практической работы был создан веб-интерфейс, демонстрирующий работу основных HTML5 API.  
Приложение корректно обрабатывает навигацию, анимацию и фоновые вычисления, оставаясь отзывчивым и удобным для пользователя.
